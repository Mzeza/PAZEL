# پلنر موبایلی
این پروژه یک وب‌سایت موبایل‌محور Planner است.

ویژگی‌ها:
- سه تب پایین: یادداشت‌ها و اهداف، پلنر ساعتی، عادت‌های ماه
- تقویم ماهانه و انتخاب روز
- برنامه‌ریزی 24 ساعته برای هر روز
- عادت‌های ماه و ثبت انجام عادت در هر روز
- اهداف سال، ماه و هفته
- یادداشت‌ها
- ذخیره خودکار تمام اطلاعات در localStorage مرورگر
- بعد از بستن/خارج شدن از سایت، اطلاعات در همان مرورگر باقی می‌ماند
- طراحی RTL و مناسب موبایل

اجرا:
فایل index.html را در مرورگر باز کنید یا روی هاست قرار دهید.
برای نگهداری اطلاعات روی دستگاه‌های مختلف یا حساب کاربری، بعداً باید Backend و دیتابیس اضافه شود.
